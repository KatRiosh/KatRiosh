## Proyectos

### IndigoOne — Sistema Integral de Gestión Empresarial
**Desarrollo Frontend | 2026.**

- Diseño y desarrollo de interfaces para una aplicación de escritorio orientada a la gestión de una distribuidora de productos ópticos y sus ópticas clientes.
- Implementación de componentes reutilizables, navegación y módulos administrativos con interfaces intuitivas y consistentes.
- Adaptación de la identidad visual del sistema para los entornos Indigo y Ópticas.
- Integración de interfaces con servicios backend para la consulta y gestión de información.

**Tecnologías:** React, JavaScript, Tailwind CSS, Vite, React Router y Electron.

### Rediseño de Formulario de Red de Especialistas
**Desarrollo Web Frontend | México y Perú | 2025.**

- Rediseño visual de un formulario web para la inscripción de prospectos a redes de servicios funerarios, tanatólogos y mascotas.
- Implementación de formularios dinámicos con validaciones, campos condicionales y carga de archivos.
- Desarrollo de interfaces orientadas a mejorar la interacción y experiencia de los usuarios, ofreciendo una navegación clara y responsiva.

**Tecnologías:** PHP, JavaScript, HTML, CSS, Bootstrap y jQuery. Proyecto desarrollado con el framework CodeIgniter.

### Elder Companion — Sistema de Asistencia Virtual
**Diseño y Desarrollo de Interfaces para Aplicación Móvil | 2025–2026.**

- Diseño y desarrollo de interfaces para una aplicación móvil orientada al acompañamiento y seguimiento integral de adultos mayores.
- Diseño y organización visual de módulos para citas médicas, agenda y recordatorios de medicamentos.
- Desarrollo de propuestas de interfaz enfocadas en la accesibilidad, legibilidad y facilidad de uso.

**Tecnologías:** JavaScript, HTML5, CSS3 y Figma.

### Sistema de Alarma de Pánico para Vehículos
**Desarrollo Frontend | 2024–2025.**

- Diseño de la interfaz de una aplicación móvil vinculada con un dispositivo de alerta integrado en un vehículo.
- Desarrollo de pantallas para gestionar contactos de emergencia y consultar información de ubicación.
- Organización de elementos visuales para facilitar el acceso a las funciones principales de la aplicación.

**Tecnologías:** React, JavaScript, Tailwind CSS y Figma.
